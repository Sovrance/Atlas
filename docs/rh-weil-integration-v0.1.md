# RH/Weil Positivity Integration v0.1

Atlas now carries the source scaffold for the RH Research Notebook V2 under `math/rh_weil/`.

This resolves a provenance gap in older Constant Atlas prose that used `G00 > 0` and a Schur-pivot positivity test as an example of the interval-certification standard. The new module does **not** retroactively certify those prose statements. Its imported certificate is deliberately `IMPORTED_PENDING_REGENERATION` until the results are reproduced by Atlas-native code.

No finite polynomial block is an RH proof. See `math/rh_weil/AGENT_INSTRUCTIONS.md` for the implementation and promotion gates.
